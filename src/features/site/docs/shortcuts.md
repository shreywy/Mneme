# Keyboard shortcuts

## Everywhere

| Key | Does |
|---|---|
| **[** | Collapse or expand the sidebar |
| **F** | Focus mode |
| **Esc** | Close, go back, or leave focus mode |
| **Right-click** | The menu for whatever is under the pointer |

## Studying

| Key | Does |
|---|---|
| **1**–**9** | Pick an answer |
| **Enter** / **Space** | Check, continue, flip a flashcard |
| **←** / **→** | Previous / next (Flashcards, Test) |
| **M** | Sound on or off |

## Notes pages

| Key | Does |
|---|---|
| **Ctrl+F** | Find on the page |

## Pages

| Key | Does |
|---|---|
| **T** / **V** / **H** | Type / select / move around |
| **P** / **M** / **E** / **L** | Pen / highlighter / eraser / lasso |
| **I** or **/** | Insert |
| **1**–**4** (in Insert) | A recent insert |
| **Ctrl+Z** / **Ctrl+Shift+Z** | Undo / redo |
| **Ctrl+A** | Select everything on the page |
| **Ctrl+D** | Duplicate the selection |
| **Delete** | Delete the selection |
| **Ctrl+P** | Print or save as PDF |
| **Space** + drag | Move around |
| **Ctrl** + wheel | Zoom |
| **Alt** while dragging | Place off the grid |
| **Arrows** on a focused grip | Move a block a line (Shift: four) |
