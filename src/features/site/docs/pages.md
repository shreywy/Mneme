# Pages

A page is an endless sheet of paper for your own writing. It works best on a computer; on a phone it opens in **Read** view, where you can still tap a paragraph to edit it.

## The paper

- Click anywhere to start writing there. Everything snaps to one grid, so text in blocks side by side shares the same lines.
- **Pan** with the wheel, a trackpad, the middle mouse button, or Space + drag. **Zoom** with Ctrl + wheel or a pinch.
- **Recenter page** takes you back to where the page starts. The map in the corner shows everything on the page; click it to jump.
- **Page settings → Paper**: lines (none, ruled, dots, squares), spacing, line strength and colour, a red margin line, paper colour, light or dark for this page only, and the font. Save it as the start for new pages.

## Writing

Markdown shortcuts work as you type: `#`, `##`, `###`, `-`, `1.`, `[]`, `>`, `---`, ```` ``` ```` and `$$`. The toolbar along the top has headings, eight fonts, sizes, colours, highlight, links, lists and undo.

## Insert

Press **I** or **/**, or the **+** beside an empty line.

| Letter | Inserts |
|---|---|
| **E** | Equation, typed with a maths keyboard (type `sqrt`, `/`, `theta`) |
| **W** | Step-by-step working |
| **P** | A plot of `y = …` |
| **A** | Blank axes |
| **M** | A picture |
| **T** | A table (pick its size; **+** on its edges adds rows and columns) |
| **C** | Code, highlighted, with a language picker and Copy |
| **K** | A checklist |
| **Q** | A quote |
| **L** | A link to a deck, notes page or another page |

**1**–**4** repeat your recent inserts. Drag a tile onto the paper to put it exactly there.

**Smart paste:** cells from a spreadsheet become a table, LaTeX becomes an equation, code from an editor becomes a code block, and a picture becomes a picture. A toast offers **Paste as plain text** if that's not what you wanted.

**My blocks:** select blocks you've set up just so (a table, labelled axes), right-click → **Save as my block**, and they're in Insert on every page.

## Drawing

| Key | Tool |
|---|---|
| **P** | Pen: three colours, thickness, pressure and smoothing |
| **M** | Highlighter: goes behind the text, and a stroke along a line straightens onto it |
| **E** | Eraser: whole strokes, or rub out just part of one |
| **L** | Lasso: select drawing and blocks to move, copy, recolour or delete |
| **T** / **V** / **H** | Back to typing / select / move around |

**Hold at the end of a stroke** and it becomes a clean line, rectangle, ellipse or triangle, snapped to the grid (hold Alt to keep it off the grid). Drawing over a block sticks to that block and moves with it. On a tablet, once you've used a pen, your hand resting on the screen doesn't draw and one finger moves the page; tap with two fingers to undo.

**Ctrl+Z** undoes typing inside a block; on the paper it undoes moves, deletes and drawing, in order.

## Pictures

Paste, drop or insert a picture. It's shrunk to 2000 px on its longest side and uploaded to Imgur (the first time, Mneme asks you to agree to that). Your page keeps only the link. Drag the corner to resize; add a caption and alt text. Deleting a picture deletes it from Imgur.

## Pages layout and printing

**Page settings → Layout → Pages** lays the main column out on A4 or Letter sheets, with page numbers if you like. Something that would cross the bottom of a sheet moves whole to the next one.

**⋯ → Print** or **Save as PDF** (or **Ctrl+P**) prints the page as a clean document. Text in the PDF stays selectable.

## Sharing

**⋯ → Share** makes a read-only link. Tick **Include my drawing** to send the pen and highlighter along. Anyone with the link can read it; signed in, they can save their own copy.
