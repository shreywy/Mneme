## Phase 2: putting things on the page

12. **Insert panel.** Press **I** (when not typing), click **Insert** in the bottom bar, or click the **+** beside an empty line.
    - A letter inserts straight away: E equation, P plot, A axes, T table, W working, C code, K checklist, Q quote, L link.
    - 1–4 repeat your last four.
    - Drag a tile onto the paper to put it exactly there.
    - Notes:
13. **/ menu.** Type `/` while writing, then keep typing to filter (`/plo`, `/h2`, `/table`). Use the arrow keys and Enter.
    - Notes:
14. **Equation.** Type `$$` and press Enter, or press E in Insert. Type maths with the keyboard (`sqrt`, `/` for a fraction, `theta`, `^` for powers) or the buttons. **LaTeX** shows the raw code. Click the equation later to edit it.
    - Notes:
15. **Maths in a sentence.** Type `$v^2$`. It turns into maths when you type the closing `$`. "$5 and $10" stays as text.
    - Notes:
16. **Step-by-step working.** One row per step: left side, =, right side, and why. Enter adds a step.
    - Notes:
17. **Plot and axes.** Type a formula such as `100 / x`. Add more lines, set the x range, and optionally y and the labels. Axes gives you blank, labelled axes.
    - Notes:
18. **Table.** Every row is exactly one line. Tab moves between cells. When the cursor is in a table, the toolbar gets + Row, + Col, − Row, − Col and delete-table buttons.
    - Notes:
19. **Code block.** Pick the language at the top-left; use Copy at the top-right.
    - Notes:
20. **Link a deck or page.** Press L. The card shows the deck or page's current title and has an Open button.
    - Notes:
21. **Smart paste.** Each turns into a block, with a **Paste as plain text** button in case you didn't want that:
    - cells copied from Sheets or Excel → a table
    - LaTeX such as `\frac{a}{b}` → an equation
    - code copied from VS Code → a code block in the right language
    - a link to one of your decks or pages → a card
    - Notes:
22. **My blocks.** Select one or more blocks and click **Save** in the bar above them (or right-click → Save as my block). It appears under My blocks in Insert on every page, and you can drag it out.
    - Notes:
23. **Right-click** a block (duplicate, save, bring to front, send to back, delete), a bookmark, or empty paper (write here, insert here, bookmark, select all, recenter).
    - Notes:
24. **Duplicate** with Ctrl+D on a selection.
    - Notes:
25. **On a phone**, Read view now has the toolbar and Insert at the top while you edit.
    - Notes:
